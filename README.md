# Cardiovascular Disease Prediction

## Project Overview

This project predicts the likelihood of cardiovascular disease using machine learning techniques. The dataset was cleaned and preprocessed, followed by Exploratory Data Analysis (EDA) and correlation analysis.

## Dataset

- Dataset: cardio_train.csv
- The dataset contains patient health and lifestyle-related features used for cardiovascular disease prediction.

## Exploratory Data Analysis

A total of 12 EDA visualizations were created to understand the dataset and identify important patterns and relationships.

## Machine Learning Models

The following machine learning algorithms were implemented and compared:

- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Decision Tree
- Logistic Regression
- Random Forest

## Model Performance

Among the tested models, SVM achieved the highest accuracy of **73.66%**.

## Final Model

The final cardiovascular disease prediction model was developed using **Support Vector Machine (SVM)**.
